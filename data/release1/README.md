# Attached Subtask 2 training release (English, chunk 1)

`data.zip` is the exact reassembled archive uploaded by the user in three parts. It is **84,957,589 bytes**, with SHA-256 `ad18b9e877abb2f6a469bc7df0e855bebc684ead6a81d0e332765bff8e071fa9`. The ZIP passes `ZipFile.testzip()`. It contains 400 labeled English Subtask 2 image/article pairs and a separate Subtask 1 text corpus. The archive calls the Subtask 2 portion **training data, chunk 1**. It is not evidence that all eventual competition training languages or splits are present.

The tracked `manifest.csv`, `framing-labels.txt`, and `provenance.json` were generated by:

```bash
python -m framing prepare-release --archive data/release1/data.zip --out data/release1
```

That command verifies every Subtask 2 annotation against an image and an article with the same numeric document ID, validates the 14-label vocabulary found in the archive, and extracts only the 400 image/article pairs to the ignored `extracted/` directory. It does not run or follow any instructions from files inside the ZIP. Run it after cloning before auditing or training. The associated HTML files are for human browsing and are not model inputs.

The package supplies **image** labels for all 400 pairs. It does not supply paired gold **article-frame** labels for these articles; the Subtask 1 files describe a separate corpus. Therefore, this release supports image-only and Subtask 2a experiments, but not a gold-context Subtask 2b experiment. Do not fill `text_labels` from the separate corpus.
